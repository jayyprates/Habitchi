# Habitchi Board

**Componentes:**

* Arduino Nano V3 (ATmega328P)
* Tela e-paper Waveshare de 2,66"

O projeto é desenvolvido em C++, utilizando o **PlatformIO** como gerenciador do projeto.

**PINS**
```
// BUTTONS
constexpr uint8_t OK_BUTTON_PIN = 2;
constexpr uint8_t UP_BUTTON_PIN = 3;
constexpr uint8_t DOWN_BUTTON_PIN = 4;

// DISPLAY
constexpr uint8_t DISPLAY_CS_PIN   = 6;
constexpr uint8_t DISPLAY_DC_PIN   = 7;
constexpr uint8_t DISPLAY_RST_PIN  = 8;
constexpr uint8_t DISPLAY_BUSY_PIN = 9;
```
