# #1 Definição do Projeto 

Usamos a primeira reunião do grupo para compartilhar ideias para o projeto. Com o prazo em mente e as instruções do trabalho, decidimos criar um bichinho virtual inspirado no tamagotchi para ajudar na preservação de hábitos saudáveis e chamamos de Habitchi. 

Entendemos que o projeto atende as exigências do professor, pois abarca: 
- Entrada de dados
- Processamento 
- Saída

Optamos por criar o projeto no GitHub para facilitar a divisão de tarefas e o versionamento do código. Também definimos os materias que seriam utilizados no hardware do Habitchi. Atualmente utilizamos: 
- Tela E-Ink Waveshare 2,66"
- Arduino Nano 

Você encontra o repositório [aqui](https://github.com/jayyprates/Habitchi).
